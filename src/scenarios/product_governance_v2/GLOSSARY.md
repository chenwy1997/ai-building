# 商品治理 V2

以固定类目基线和统一属性建模标准为依据，分步产生、检查和评审属性，保存依据与版本，供后续商品治理使用。

## Language

**类目基线**：本次治理采用的固定类目树及其版本。任务按类目 ID 选择范围，同名类目不视为同一个节点。

**同族类目**：商品的基本形态、用途和主要参数相近，按少数特征区分的一组类目，例如有芯小卷纸与无芯小卷纸。同族可以跨直接父类目，同父节点只是识别线索。

**同族属性基线**：同族类目共同采用的属性定义与配置约定。各末级类目保有能够由业务解释的差异。

**候选基线**：尚待业务确认的同族共同属性方案。它与依赖它产生的末级草案共同构成待审结果。

**已确认基线**：经业务验收、可作为后续建模复用依据的同族共同属性标准。

**同族候选**：与目标类目的商品对象或主要参数相关、尚需核对是否同族的类目。找到相关类目与确认其属于同族是两个判断。

**同族验收样板**：经人工确认的同族成员判断、分组理由及易混淆反例，用于检验同族发现与归组是否符合业务要求。

**属性池**：供类目建模参考和复用的属性定义集合，包含各定义的含义、计量口径、适用范围及确认状态。

**领域知识包**：面向某类或同族商品的可复用业务知识，包含对象边界、选型维度、术语与计量口径、参考资料及易错反例。已核实的依据与尚待验证的提议分别注明。

**专业疑点**：影响关键选型或正确填写、现有资料仍不足以确定的领域问题，例如参数定义、单位口径或适配关系不明确。它与是否需要强制填写分别判断。

**属性定义**：一个商品参数的含义、描述对象和取值结构，例如纸张层数或单片展开尺寸。它与挂在哪些类目下分别建模。

**枚举修订候选**：已确认属于某属性含义、现有选项尚未覆盖的真实取值及其依据，尚待纳入该属性的正式取值范围。同义词归一不构成新取值。

**多选属性**：同一商品在同一取值口径下可同时具有多个真实取值的属性。尚不明确的多个可能值、不同规格各自的取值，不构成同一商品的多选。

**属性价值**：一个参数对采购选型、同品或规格比较、搜索、展示的具体用途。属性有价值与要求每件商品必须填写，是两个不同判断。

**必填性**：一个属性在某个类目中是否要求填写的业务约定，分为必填与选填。

**系统基础字段**：供应链系统中已由固定业务职责和维护入口管理的商品信息，例如品牌、供应商、规格名称和销售单位。

**销售单位**：一个销售单元的包装规格表达，例如个、袋、10支/盒或500g/袋。它与描述包装内含物的计数单位含义不同。

**类目属性绑定**：某属性用于某末级类目的约定，包含适用性、必填性和用途。本轮治理统一逐SKU填写，公共属性也须明确适用类目。

**关键规格**：在销售端用于买家选择商品规格的属性维度。逐SKU填写的属性是否属于关键规格，按实际选购用途分别确定。

**商品重挂**：把商品从当前实际挂载目录调整到已核实的目标目录。它与修改标准类目归属分别核对，相关属性值按目标定义制定迁移方案。

**变更提案**：拟调整商品归属、属性配置或属性值的具体记录，呈现对象、当前与目标内容、依据及影响，供审核和后续执行使用。提案产出不表示已经确认或执行。

**写入冲突**：待执行变更所涉及对象的当前内容或相关版本，已不符合审核提案确认的执行前提。它与商品资料之间的证据冲突分别处理。

**执行结果未知**：操作已发出，但现有回执和记录不足以确认其成功或失败的状态。未知不等于已经失败或尚未执行。

**变更核验**：对执行后的实际内容与已确认目标是否一致作出的检查。核心数据符合目标与搜索、展示等后续使用效果生效分别记录。

**变更回退**：为撤回本次已执行改动而进行的后续变更，需界定能撤回的内容及后续修改、引用的影响。它不等于将所有相关对象恢复成某个历史快照。

**属性卡**：属性定义、类目绑定、取值规则、来源与评审记录组合形成的可阅读视图。它不是另一份独立维护的标准。

**审核视图**：按一类审核任务组织的业务信息、判断入口与追溯内容。本轮主要分为属性方案审核、商品归属与填值审核。

**小屏验收**：在目标设备、应用、缩放及可用视窗中完成实际审核任务，确认信息可读、操作可达、全文可追溯及意见可保持的验收。

**审核结论**：针对某业务对象及对应内容作出的审核判断，其有效性受相关内容与依据是否发生实质变化影响。

**待复核**：原审核结论涉及的内容或依据发生实质变化，尚需重新确认的状态。历史意见保留供追溯。

**严重问题**：会导致错误选型、错误归属、计量或取值失真，或妨碍关键审核判断与操作的问题。

**研发案例**：用于分析问题、改进规范、知识及生成或审核方法的业务案例，其已知答案可以用于调优。

**保留验收案例**：有人工判定结果、尚未用于相应审核方法调优的案例，用于独立验证审核能力。用于调优后不再具有保留验证身份。

**构造反例**：为检验业务边界或错误识别而人为编写、修改的案例，来源与真实业务观测区别记录。

**错误模式**：因相同业务混淆或规则缺陷，在不同结果中出现的一类问题，例如把销售总量当成单包量。

**漏检**：人工判定存在且属于本次审核范围的问题，审核器未能指出。

**误报**：审核器将人工判定正确或允许的处理报告为错误。

**填充率**：约定范围中已填业务值占应统计填写项的比例，须说明统计对象和分母。它衡量填写数量，不能独立证明取值正确。

**公共属性**：多个类目共享稳定含义的属性定义。公共不表示所有类目必填，也不表示所有类目取值规则相同。

**公开属性**：允许在销售端对外展示的属性。公开与多个类目共用的公共，是两个不同维度。

**类目特性属性**：描述某类或同族商品特征、采购参数或使用条件的属性定义。不同类目中的同义参数具有相同含义与计量口径，名称相同而含义不同的参数分别界定。

**建模依据**：用于判断类目需要哪些属性及其含义、类型和取值规则的业务需求、领域知识与专业参考。当前挂载商品的资料不界定必要属性的全集。

**取值证据**：用于确定某一件商品某项属性值的具体资料，例如该商品的标题、规格、详情、图片或经核实的同品资料。

**补证适用范围**：经核验，一项外部资料可支持目标商品哪些参数、变体、版本及计量范围的约定。某项参数可用不代表该资料中的全部内容都可复用。

**图片证据**：来源及对应商品明确、可定位具体内容的商品图像资料。在本轮治理中作为补充使用，图中文字转写与未经验证的视觉推断区别记录。

**未知**：现有资料不足以确定某件商品某项属性值的状态。它不表示否、零或已确认不适用。

**不适用**：有依据确认某属性对这件商品没有业务含义的状态。资料缺失不构成不适用。

**默认值**：属性配置中预先指定、用于初始化或建议填写的值。预填本身不证明商品具有该值。

**派生值**：根据已核实事实，按明确规则得出的属性值。它与原始资料中直接明示的值区别记录。

**直接值**：资料中直接明示、能对应到该商品及属性口径的值。直接明示不自动消除与其他资料的冲突。

**证据冲突**：适用于同一商品、同一属性口径及相应版本的资料给出不相容事实，且尚无依据排除其中一方。不同规格各自的值不构成同一商品的证据冲突。

**来源记录**：属性候选或规则的提出依据及可追溯定位。模型知识是提出线索，不能声称已经核验某网站或反推出训练语料出处。

**判定依据**：评审一项定义或绑定时引用的业务需要、类目边界、标准资料或反例。依据类别与通过、修改、拒绝、待补证的评审结论分开记录。

**标准版本**：一组共同发布、内容固定的定义、绑定、规则、类目引用及所依赖的知识约定。新任务采用最新已发布版本，运行中的任务固定原版本；执行方法是否与其一致须分别核验。

**取值口径**：一个值描述的对象与计量范围，例如单片、每包、每卷或整个销售单元。数值、单位相同也不能代替口径一致。

**属性名**：便于业务人员辨认参数的名称，含义由属性定义和取值口径约束。简洁不能以丢失对象或计量范围为代价。

**计数单位**：数量所数对象的单位，例如张、抽、卷。它不同于交易时按箱、提等表达的销售单位。

**数量参数**：描述某对象在特定计量范围内数量的参数，例如每包5张。数值、单位和计量范围共同限定其含义。

**包装层级**：商品包装由内到外的计量层次，例如单张、包、提、箱；各层之间的数量关系必须有明确依据。
