# 商品治理 V2

以固定类目基线和统一属性建模标准为依据，分步产生、检查和评审属性，保存依据与版本，供后续商品治理使用。

## Language

**类目基线**：本次治理采用的固定类目树及其版本。任务按类目 ID 选择范围，同名类目不视为同一个节点。

**属性定义**：一个业务概念的含义、描述对象和取值结构，例如品牌或单片展开尺寸。它与挂在哪些类目下分别建模。

**类目属性绑定**：某属性用于某末级类目的约定，包含适用性、必填性、用途和取值承载层级。公共属性也必须明确绑定条件。

**属性卡**：属性定义、类目绑定、取值规则、来源与评审记录组合形成的可阅读视图。它不是另一份独立维护的标准。

**公共属性**：多个类目共享稳定含义的属性定义。公共不表示所有类目必填，也不表示所有类目取值规则相同。

**类目特性属性**：描述某类商品特征、采购参数或使用条件的属性定义。跨类目复用须先确认含义与计量口径一致。

**来源记录**：属性候选或规则的提出依据及可追溯定位。模型知识是提出线索，不能声称已经核验某网站或反推出训练语料出处。

**判定依据**：评审一项定义或绑定时引用的业务需要、类目边界、标准资料或反例。依据类别与通过、修改、拒绝、待补证的评审结论分开记录。

**标准版本**：一组共同发布、内容固定的定义、绑定、规则和类目引用。新任务采用最新已发布版本，运行中的任务固定原版本。

**取值口径**：一个值描述的对象与计量范围，例如单片、每包、每卷或整个销售单元。数值、单位相同也不能代替口径一致。
