# 取值与计量 v1
值的单位与计量范围分别建模：单片、每抽、每包、每卷、每件或销售单元。张、抽、片、层不能默认等价。
属性卡包含直接取值规则、允许公式、输入单位/范围、计算前提、冲突处理、缺项处理及正反例。
公式只用登记算子direct/divide/multiply，不执行生成代码。divide必须有同商品、同范围、非零除数等条件；未知数量不得反推。
总量÷包数仅在总量和包数属于同一销售组合、包装同质、赠品处理明确且能够整除时使用。没有这些证据则保留直接值或待补证。
颜色只提取颜色本义，不把标题、型号、尺寸、整个销售规格当成颜色。尺寸明确长宽厚的含义，不能把厚度替代平面尺寸。
unknown不是false，缺项不是零，资料未提到不是“不含”。互相冲突的来源保留冲突，不按模型猜测消除。
正反例是合成测试，标注synthetic；示例通过只证明规则处理这几个例子，不代表商品准确率。
