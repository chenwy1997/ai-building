# 本地参考与共用规则 r2
机器约束以同目录shared-policy.json为唯一清单，提示词携带该文件，程序按同一清单校验。

震坤行来源是用户提供本地Excel，不通过网页替代。M45112「清洁纸品」是上位模板，不是三横21个末级的等价模板。每个来源行、每个目标类目均记录采纳/调整采纳/不采纳、目标字段和理由；已有合适字段可吸收依据，不为采纳而重复造字段。
名称可属于商品基础主数据，不必重复为类目属性。型号在震坤行必填不意味着三横也必填。包装规格可拆成可计算数量和包装形态，计量单位若已有交易主数据则应记录其边界；不要凭资料少否定真实业务价值。
外部单选/多选须适配本系统五类类型。层数优先数值，重复与“4层及以上”等范围枚举不能直接当精确层数；印花与压花不同。香型不能因未提到而默认无香。盒/袋/桶是容器形态，提/箱可能是外层包装层级；混层枚举须拆分或限定口径。
是否套装先定义同质多包与异质组合的边界；不以多包自动当套装。外部套装组合示例含洗护品，不适用于纸品；可借鉴结构并重写合成正反例，注明来源只支持字段思想。
核心必填缺项仍记缺项；condition不得写“资料有时必填”。公共品牌和制造商型号保持定义一致；包装/尺寸等变化按SKU绑定。
未知不落入其他，不默认false/0；已知枚举外值保留原文。每包量与销售总量分离。算式须有同SKU、同销售单元、同质包装、赠品已明确及独立直接证据；计算结果不能循环作为自己的输入。
外部模板未覆盖的已核实业务需求继续保留；不因参考未列就删除。纸巾盒等配件不得套用纸巾的层数、纸浆、香型、印花参数。
本轮只补本地参考审核和共用规则回归，不重跑ES采样或整批属性生成；不开展商品批量填写。
