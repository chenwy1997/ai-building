# 先制定同族共同属性基线，再处理末级类目差异

有芯与无芯小卷纸等相近类目独立生成完整属性卡，已出现同义维度命名、类型、单位与属性集合漂移。根据2026-10-22对Q6及Q8的确认，后续按商品对象、主要结构和选型参数识别同族，允许跨直接父节点；先制定同族共同属性基线，生成前参考已有属性池，再表达末级类目有业务依据的差异。该选择使建模与审核需要考虑跨类目依赖，换取共同参数的一致性；基线错误传播、具体检索与确认机制及后台继承挂载位置仍待讨论，不自动改变目录树或历史结果。

Q13进一步确认：末级任务对共享名称、定义、类型、单位或枚举的修改先形成提案，在研发流程内集中处理为新基线版本，并检查受影响引用；本类特有需求可保留为有理由的局部差异。该协调不要求运营对每次研发修订逐条审批，正式采用仍按共同约定的业务验收流程。
