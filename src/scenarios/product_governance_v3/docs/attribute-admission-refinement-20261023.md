## 已落地的通用规则与接线

| 改动 | 实际承接 | 仍需人工判断 |
| --- | --- | --- |
| 属性先证明业务用途和维护收益 | 规范、R07及五阶段skill/必读判例已更新，按同版release实际进入请求上下文 | “供比较/展示”是否有具体场景，收益是否值得维护 |
| 扩展候选独立承载 | 建模JSON及冻结族增加extensionCandidates，包含潜在用途、暂缓原因、启用条件及引用；没有类型配置或SKU绑定 | 应采用、暂缓还是排除，候选启用的业务裁定 |
| 防止候选混入执行 | 同族预取和get_family_context传回候选；属性池、SKU合同和原生投影只消费attributes。程序检查基础职责、重复/重叠、叶类启用冻结候选、引用及合同外取值 | 语义别名不能仅靠ID/概念/名称与scope比较穷尽 |
| 不强迫凑属性 | 新族可以没有准入属性，以候选或unresolved说明原因；SKU阶段仍要求适用固定合同 | 没有属性是否符合实际业务，不意味着可以漏掉必要参数 |
| 名称简洁、定义精确 | 建模/研究/提取/填值/审核skill统一说明必要限定、开放文本、外部字段语义与计数词边界 | 名称是否直观，净/毛、内/外等语义是否需要保留 |
| 外部字段与词语关系核实 | 专业包分别记录标签、值、单位、对象及资料读取范围。计数词未确认不换算，工艺不强做互斥枚举 | 具体专业定义及来源是否适用于目标型号 |

这里没有把所有命名或采购必要性都编成正则检查。程序通过只能证明已实施的结构与引用约束，不能证明AI理解已经与采购人员一致。小卷纸暂缓某些参数不是其他类目的删除名单；有明确适配用途的尺寸仍可进入相应类目方案。

旧format=2快照可省略族的扩展数组，以空候选读取；本版建模输出必须携带该数组。已冻结候选的启用/修改与共同属性变更一样先另提共享修订。本轮直接修订的是本地待审样板基线，没有发布为公司标准。

## 当前卷纸方案

主表7项共用选填定义：是否无芯、层数、单卷重量、原料、纸张尺寸、每卷数量、香型。是否无芯在有芯与无芯两类均保留；基础字段职责不变。

- 单卷重量缩短名称，仍保持来源明示的每卷重量及含芯/包装边界，不变成去芯净纸重或实测值。
- 每卷数量为暂名，保留数量及原计数词文本。张/节/格定义、统一名称及数值化未裁定，不按层数倍乘、不跨单位比较，不改成笼统“单卷规格”。
- 香型保持一个文本类型。当前identity提取保留“无香味”“有香味”或具体香型的原词，未说明留未知；只知有香时不编香型，细节缺口在治理记录说明。统一展示词表及相应归一化器尚未接入。
- 印花、压花、卷外径、卷宽、纸芯内径、单卷长度共6项进入独立扩展候选，不在待填属性或原生配置中。候选来自同一冻结族，Excel不再自行维护另一套尺寸定义。启用前重新确认本业务用途、术语关系与类型/单位/绑定。

专业查证增补见[知识包](../knowledge/small-roll-paper-research-20261022.md)：维达VD4169、Tork100200已读参数正文，分别支持区分计量对象、检查标签和值，以及印花/压花不等同。舒洁0562-10仅取得搜索摘要，同标题并列200格与200张/卷；正文取回超时，未取得本批0097/0316技术书。这个线索不证明张/节/格通用等价，也不消除本批260张与60张的数量冲突。山东航空采购公告同样仅取得搜索摘要，只作为特定采购场景使用工艺/尺寸的研究线索。
