## 公共组件与编排边界

| 组件 | 职责与复用位置 |
| --- | --- |
| `budget.ts` | 既有公共账本：并发预留、持久化、显式授权调整；无类目/轮次策略 |
| `request-journal.ts` | 请求、响应、回执一致性及未知结果检查；批次账本校验、历史复核和续跑共用 |
| `runtime-errors.ts` | 已知模型参数错误与可恢复停止分类；未知HTTP/业务错误不猜测为可重试 |
| `transcript-replay.ts` | 任意阶段请求的精确校验与重放；离线到达新请求边界即停止，执行时委托原缓存/预算客户端 |
| `runner.ts` | 既有通用工具循环；接受只读重放客户端，完整执行原轮数、工具与纠错计数 |
| `family-coverage.ts` | 根据输入快照和分组列出新建、已有及未归族覆盖；不做语义判定 |
| `batch-resume.ts` | 读取来源轮次、动态筛选任务、复用基线、调用公共重放器并汇总；不绑定清洁纸品或12这个数量 |
