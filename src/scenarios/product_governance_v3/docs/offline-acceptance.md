# v3离线接线验收

日期：2026-10-22。范围是当前接线，实现入口和命令见[README](../README.md)。不涉及收费模型运行、生产变更或原Excel修改。

[全面审计](implementation-audit-20261022.md)先发现原45项测试未覆盖的漏接和程序边界；现已完成[第1、2步修复与回归](implementation-phase12-20261022.md)。原20项观测保留历史，当前行为由新回归断言验证，不把原观测改写成通过。

执行链使用实际`assemble → ResponsesClient → ToolRegistry → runStage → checkResult → 持久记录`，仅HTTP返回由脚本模拟。四阶段均先返回function调用，再验证对应结果和完整历史已进入下一请求，最后输出结构化候选。

本次结果：v3的79项测试、相关v2的18项回归测试、v3范围类型检查及4个skill校验全部通过。另有全11工具的实际function组调用/配对回传测试。四阶段共8次模拟HTTP响应；再次运行重放8份缓存，新增发送为0。没有真实DeepSeek请求或生产写入。

验收包括：

- 必要规范、供应链承接合同、R01—R26职责映射、阶段skill和判例正文进入请求；原漏接章节已补入。必读知识缺失在请求前阻断依赖阶段，研究阶段保留专业问题。
- 有芯/无芯共用“是否无芯”和统一属性定义；其他批候选、在途依赖、全局池冒充填写合同被挡住。
- 版本化职责表的最低覆盖及内容漂移校验；基础字段重复、conditional、SPU、独立单位字段、重复概念、非法多值/枚举及不支持的索引声明被挡住。
- 已读范围、来源/事实引用、SKU/销售单位、口径/单位/值、计算因子策略、均一和赠品依据实际检查；错误因子、抽/张互换、分数计数及零除数被挡住。
- false和0原样保留；未知值不补false/0；矛盾不被算式或单个来源覆盖。
- 共同定义/类目绑定分离，理由充分的绑定差异不误拦；数值/文本/选项和展示配置进入真实结果及离线原生投影。
- 知识与SKU引用分开，白名单中未命中名称路由的资料可发现/补读；计算策略ID、版本、因子约束可发现并从真实工具输出组装推导。
- 计算前提及因子冲突、负数/分数计数因子、非法日历日期、数值精度/范围、文本长度/格式和多选计数实际检查；有符号测量和等价多选顺序不误拦。
- 事实准备固定原文及SKU/组合/版本，漂移或未准备事实不能授权known/计算；连续片段的跨边界事实及完整quote实际回传，未读间隙不算已读。
- 实际搜索、分页游标和多轮工具往返；禁止的工具、阶段越界、额外参数、任意路径、循环/字节超限及重复call_id被挡住。
- 同一请求并发只发送一次；恢复重用持久响应；未知结果不重发；并发累计预留不越预算；改版本不复用旧请求；孤立副本内篡改材料后加载失败。

前一轮曾对真实本地v2树13,587节点进行只读搜索及子树遍历，返回有芯/无芯真实ID；本轮未重复该未变算法验收，不把历史只读验证冒称当前业务治理结果。接线fixture保持明确构造标记。

当前机器报告为本目录的[acceptance.json](acceptance.json)，回归见[wiring.test.ts](../wiring.test.ts)和[contracts-regression.test.ts](../contracts-regression.test.ts)。报告不声称DeepSeek真实表现、业务留出集准确率、人审替代能力、专业知识完整性、完整阶段流转或新版Excel视觉验收合格。
