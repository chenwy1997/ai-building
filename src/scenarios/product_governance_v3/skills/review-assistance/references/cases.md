# 审核判例

正例：指出两个末级类目缺少共同“是否无芯”定义，定位具体对象及R03；发现计算有结果无因子证据，按R14要求补因子或保留未知。

反例：生成器给自己打98分即视为通过；把“没发现问题”写成可写生产；从Excel列宽配置就声称已完成13寸WPS视觉验收。

真实业务验收、构造程序用例与留出集必须分开报告；当前离线接线用例不构成AI审核能力评估。

职责回归：R02的required/optional枚举由程序检查，必填理由是否成立仍是人工问题；R26的严重项隔离、结束条件、写后核验与回退进入审核上下文，但对应生产执行器未实施，不能写成已验收。原文“否”却被错误准备成true，即使格式及hash一致，也仍需要事实核实和人审；准备记录不是语义正确率证明。

准入与命名回归：指出“仅供展示”没有具体场景，但不能一律删除所有展示属性；建议核实用途并进入扩展候选。名称缩短同时检查重量口径是否仍明确，不能误拦有区分作用的内径/外径等名字。候选有真实资料也不等于允许绕过共享修订启用。

语义反例：把电商已有字段当完整标准；把未读正文的搜索线索写成专业结论；将尚未确定的张/节/格转换记为已核实。程序能检查候选分离和不在合同的值，不能自动判断所有名称是否直观或业务收益是否成立。
