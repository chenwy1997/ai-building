# 取值判例

正例：同一销售组合来源明示每提10卷、每销售单位4提、均一且无赠品，引用这两个冻结事实计算40卷/销售单位；计算结果必须对应目标口径。

反例：模型说10×4=40却没有两个因子的原文定位；把另一个SKU的10卷/提拿来乘；把5抽等同5张；缺失“是否无芯”直接写false。

边界例：每包数量定义单位固定张/包，值5显示为5张/包；未知写null及原因，而不是文字“未知”或0。不同口径的净重和毛重不能当来源矛盾强行覆盖。

漏检回归：-10卷/提×-4提虽然得到40，两个计数因子均非法；同范围同时存在“无赠品”和“有赠品”时不能只引用前者。策略ID/版本、因子顺序与范围从calculation_policies取得，不能臆造。measurement策略允许有依据的有符号量，不能把所有负数都按计数拒绝。

误拦回归：引文跨两个相邻已读片段时，sources_read会在完整覆盖后回传对应事实与完整quote；隔着未读字符的两个片段不算完整读取。2024-02-29是真实日期，2026-02-31无效，不能用Date.parse自动滚动后的结果掩盖错误。
# 扩展与文本口径补充

extensionCandidates只是研究线索，不填写unknown占位，也不因有资料就新增值。原文280格/卷不换成280张/卷；香型原文有香味可保留粗粒度事实，未知具体香型在治理记录说明，未说明不能填无香。改短名称不把来源重量自动变成净纸重。
