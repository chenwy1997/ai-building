# 字段职责核对表

最新决定（2026-10-29）：保质期、本体尺寸和重量恢复选填候选；包装长宽高、毛重/物流重量、保修期及其他历史职责排除项保持排除。既有认可属性保留，详见 [字段恢复选择](field-restoration-selection.md)。

旧规范有 86 条职责映射，前 20 条为业务归并组；完整底层字段盘点为 233 条。它们不是 86 个在所有类目都能填写的独立输入框。

保质期目前只能定位到 StdProduct.warranty 数据字段与 CategoryKeyConfig.warrantyKey 映射，未核实目标蚊香目录的有效 PropertyInstance；因此无法指认一个所有商品都能填写的统一位置。旧排除依据不足，本版恢复保质期候选。

实际入口：商品 → 添加/编辑 → 选择实际目录 → SPU/SKU区域按有效继承属性生成。目录属性详情中核 title/key、目录实例版本、asSpec、显示条件；不可只看标准商品表列。数值或下拉不决定归属。
