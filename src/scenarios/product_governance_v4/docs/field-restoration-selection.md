# 历史字段恢复选择

2026-10-29 用户已选择下列范围，并随后纠正：**保修期不用，保质期要**。这次开放的是选填候选资格，不是每个类目必须新增这些属性。已有认可属性保留，不重复建立已有“尺寸”。

| 组 | 当前决定 | 具体边界 |
|---|---|---|
| 保质期 | 保留选填候选 | 指规定储存条件下的质量/使用有效期限，不是售后保修 |
| 1 重量 | 商品本体重量恢复选填候选 | 包括单卷重量、整机重量，按测量对象命名；毛重、物流重量、含包装重量保持排除 |
| 2 尺寸 | 商品本体尺寸恢复选填候选 | 优先组合尺寸，保留顺序和单位；包装长宽高不归入商品尺寸，保持排除 |
| 3 数量与计量 | 保持历史排除 | 最小计量单位、包装内数量、销售总数量；既有认可的纸张等功能计数保持 |
| 4 产地 | 保持历史排除 | 生产地、原产地、国产/进口 |
| 5 保修与质保 | 保持排除 | 保修期、质保期、质保说明；不因数据库warranty混用而恢复 |
| 6 包装与组合 | 保持历史排除 | 包装形式、单包规格、单品/套装、随附配件、套装包含物 |
| 7 配送与交付 | 保持历史排除 | 配送方式、货期、发货地 |
| 8 售后 | 保持历史排除 | 售后服务类型、说明 |
| 9 定制与安装 | 保持历史排除 | 是否定制、是否含安装 |
| 10 专属/定向 | 保持历史排除 | 专属客户商品、定向商品 |
| 11 场景与标签 | 保持历史排除 | 场景、行业、商品标签；既有认可的适用场景等属性不撤销 |

此前明确保持独立职责的组：品牌、供应商、销售单位、商品名称、规格名称、价格、起订/限购/步长、条码及供应商编码、图片附件、档案/销售状态、税务字段；型号/货号仍按此前用户决定排除。这里没有自行放开这些组。它们的全部别名与历史映射见 [完整86条清单](field-ownership-review.md)。

目录ID、SKU/SPU ID、关联ID、推送开关、利润率等技术/交易元数据单列盘点，不作为商品特性候选。

原始“商品重量”“商品长宽高”可能混有包装数据。候选可进入研究，但恢复为具体属性定义前须核本体对象和来源口径。单卷重量与整机重量同属本体重量，不共享数值和完整定义；不能把包装值改名归入本体参数。
