# 历史字段恢复待选

2026-10-28 用户决定：先只恢复**保质期**为选填候选。其余下列项目只供选择，**尚未恢复为可用候选**。原先已经认可的属性保留；本表针对历史因字段职责而被排除的内容，不把同名但不同业务对象混为一项。

| 待选组 | 涵盖字段 | 需要分清的含义 |
|---|---|---|
| 重量 | 商品重量、净重、毛重、物流重量 | 商品本体重量与含包装运输重量分开 |
| 尺寸 | 商品长宽高、包装长宽高 | 商品本体、部件适配尺寸与物流包装尺寸分开；已有认可“尺寸”保持 |
| 数量与计量 | 最小计量单位、包装内数量、销售总数量 | 包/箱/套内数量与商品功能数量分开；销售单位本身仍沿用既定排除 |
| 产地 | 生产地、原产地、国产/进口 | 与发货地分开 |
| 保修与质保 | 保修期、质保期、质保说明 | 不等于本次已恢复的保质期 |
| 包装与组合 | 包装形式、单包规格、单品/套装、随附配件、套装包含物 | 售出组成与产品功能、耗材兼容性分开 |
| 配送与交付 | 配送方式、货期、发货地 | 商家交易服务信息是否需要类目属性承载 |
| 售后 | 售后服务类型、说明 | 具体商品保障与平台统一服务规则分开 |
| 定制与安装 | 是否定制、是否含安装 | 产品特性与订单服务分开 |
| 专属/定向 | 专属客户商品、定向商品 | 通常偏销售控制，是否需要面向选型展示待选 |
| 场景与标签 | 场景标签、行业标签、商品标签 | 运营标签与已认可的“适用场景”等业务属性分开 |

此前明确保持独立职责的组：品牌、供应商、销售单位、商品名称、规格名称、价格、起订/限购/步长、条码及供应商编码、图片附件、档案/销售状态、税务字段；型号/货号仍按此前用户决定排除。这里没有自行放开这些组。它们的全部别名与历史映射见 [完整86条清单](field-ownership-review.md)。

目录ID、SKU/SPU ID、关联ID、推送开关、利润率等技术/交易元数据单列盘点，不作为商品特性候选。

用户可按组选择“恢复为选填候选 / 保持排除 / 按具体类目决定”。即使恢复，也只开放建模候选；是否适用、定义和实际目录承载仍逐类确认，不能自动填入商品值。
