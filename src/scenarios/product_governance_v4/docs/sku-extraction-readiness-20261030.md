### ES 与摘要接口各自能提供什么

- ES：全部 1,786 条有 title/rawTitle；还有真实目录、SKU/SPU、版本指针、品牌和部分 searchText。核查的顶层 saleSpec、mainImages、detailImages、detailHtml、detailText、properties、attrs、parameter 均未提供非空资料。这只说明当前索引投影不提供这些字段，不能解释成数据库没有详情。

## 数据实际如何存放

供应链不是一张拥有所有固定商品属性列的平表。主要关系是：

1. `ProductInstance.productId` 是业务 SKU；`spuProductId` 关联主商品；`id` 是实例版本，`isHead` 标记最新版本。子规格还有 prototypeId/prototypeProductId，来源归属和继承必须明确，不能把父商品某规格的数值直接传播给全部 SKU。
2. `PropertyInstance` 定义字段 key、标题、类型、是否规格属性和约束等。
3. `PropertyValueInstance` 按类型存 stringValue / numberValue / booleanValue / optionValue / fileValue 等，通过关系表关联商品实例。optionValue 和 fileValue 的多值以换行分隔。
4. `CategoryKeyConfig` 提供标题、规格、参数、详情正文、详情图、货源链接等业务职责的键映射；实际映射与目录/版本配置一起核实，默认键存在不证明目标商品有值。

后续应保留：业务 SKU/SPU、商品实例版本、真实类目及版本、原字段 key/标题/类型、原值、来源层级和获取时间。模型可以使用合并后的可读资料，审计仍需能回到原字段，不能只保存一段无边界拼接文本。

### 读取入口及限制

| 入口 | 代码核实结果 | 本次实测 |
| --- | --- | --- |
| getProductInfo | 内部读取完整详情，再投影为标题、规格、首图等摘要 | 可用；35/36 返回 |
| 管理端 getProduct_propertyArray | 返回 properties 数组，带字段 key/title/type/value 及商品实例信息 | 本地保存凭据请求返回401；浏览器现有会话可查看表单 |
| getProduct_propertyKeyValues | 将属性数组转为对象 | 不作为首选；同 key/标题可能覆盖，数组更便于保留证据 |
| 服务端 getProductDetail | 可读属性关联和原始 propertyKeyValues，并解析参数 | 已审代码；本次未直接运行服务端函数 |

完整管理端入口已定位，**尚未成为 V4 可用的批量只读适配器**。不从浏览器导出登录凭据，也不更改接口权限；后续通过正常有效鉴权或部署受控的只读字段投影接入。接口数组里的 id/instanceId 目前都来自属性实例，不能误当成 PropertyValueInstance 的值记录 ID。

现有 `parseParameterAttributes` 只支持换行及 ASCII 冒号分割。不能把它生成的空数组当成原始 HTML/中文冒号/JSON 参数确实不存在。新采集层需保留原文，再按明确格式解析，解析失败另标。

## 下一步实施顺序

1. **完整资料采集器。** 按真实目录锁定 SKU，保存 SKU/SPU/实例版本与原文快照。一次读取标题、规格、全部相关原始参数、详情正文、主/详情/规格图片、货源链接。资料状态区分未读取、读取失败、读取后为空、有有效文字、仅图片；逐 ID 对账。优先打通正常授权的批量只读入口。
2. **V4 合同驱动的事实提取与核实。** 先确认商品与类目/所售规格匹配；固定认可属性集合，不重新生成属性。每个值保留原文定位、来源、计量对象与单位。明确区分单卷/整包重量、抽/张/层、尺寸/包装尺寸、袋数量/容量。保留所有有效来源，不能静默截断长详情。
3. **按需补证。** 文字不足时使用同SKU规格图、包装标签和详情图；图片只是补充，注明识别来源和不确定性。使用货源链接或上游SKU补资料前核商品身份与规格。网络同类、模板及模型常识能帮助理解字段，不能当这件商品的值证据。
4. **程序检查与独立审校。** 检查数值/单位、布尔否定、单多选选项、计量对象、来源跨度、同SKU冲突、版本变化、缺失/不适用。真实冲突案例先形成离线回归；离线通过也不代表准确率已达标。未知不填false/0；冲突不任选一个值；已有值不静默覆盖。
5. **400件离线试填及运营复核。** 保留所有失败和缺失，报告有效资料覆盖率、可核实填写率、冲突/待核率及人工抽检准确率，分开统计。同SPU的共用资料可复用，但SKU特有值逐规格核实。先交离线值表，生产写入另立变更合同，不在本阶段做。
