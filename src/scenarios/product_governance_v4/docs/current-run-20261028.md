## 字段职责

86条历史映射全部列出，20组面向业务的职责与底层字段盘点分开。品牌、供应商、销售单位、型号等按既定政策去重；只恢复保质期为选填候选；重量、包装尺寸、产地等其他历史职责排除项先列待选，等用户决定，不自动恢复。实际职责仍需核目录实例、有效版本、继承属性和同义性。交易/技术ID只作盘点。

实际表单按有效目录属性动态生成；数据库 StdProduct.warranty 和默认 warrantyKey 不证明蚊香目录可填写保质期。保质期与保修期不视为同义。数值/下拉不是职责归属条件。

纸品原121项保持。另有90条历史纯载体排除列为恢复待选（未恢复），保留旧决定/理由；6条明确人工排除保留。不因旧属性被认可而把全部519条历史候选也当作认可。纸品款数沿用历史汇总，evidenceKeys含示例，不冒称本次逐款重算。
