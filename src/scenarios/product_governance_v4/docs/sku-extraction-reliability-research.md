# SKU 属性提取：可靠性研究与离线验收建议

日期：2026-10-30。本文研究如何评估和降低 SKU 属性提取错误，不是对现有 V4 效果的测量。本轮已另行冻结 9 类 450 件试填名单；没有独立人工金标准。[资料核验](sku-extraction-readiness-20261030.md)中的结构检查和试填程序通过都不能计算准确率。工程规则已写入 [提取与填写规范](sku-extraction-standard.md)，人工标注与统计验收仍待实施。

## 能否保证 100%？

不能事先承诺开放资料上的 AI 提取事实 100% 准确。商品证据可能缺失、互相矛盾或属于其他规格，图片/OCR 和单位换算也可能出错；模型、规则和人工都可能误判。对某个固定评估集，可以报告“人工复核后观察到的正确数 / 已核数”，包括观察到 100%，但这不是对未见商品、未来数据或证据本身真实性的保证。**正确的目标是明确风险、覆盖和不确定性，允许缺证时不填，并通过持续评估控制风险。**

结构化输出及类型检查只能约束可解析性、字段和允许值，不能保证里面的事实正确。官方文档也说明结构化输出仍会出错，输入不能支持结果时需要定义空值等处理。[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。这一来源用于说明结构与事实的区别，不限定本项目采用该服务或模型。

## 证据先于值：建议的离线工作流

1. **冻结范围。** 固定具体 SKU、商品与类目/规格身份、属性合同及其哈希、来源读取范围和版本。锁定需要检查的 SKU × 属性项目；读取失败、来源空白和不适用分别保留，不用替换 SKU 掩盖失败。
2. **先采事实，再规范化。** 每条候选值记录 SKU、共享定义及类目绑定、原文或图像定位、来源类型/时间、规格归属、原始文字/数值与单位；规范值及换算规则单独存。文字可记录字段与跨度，图片可记录图片标识、区域和识别版本。仅记录引用不等于原文真的支持该值，须审核对象、方向、数量单位和同 SKU 适用性。ALCE 将答案正确性与引文支持质量分开评估，说明有引文仍需核对支持关系。[Gao 等，2023](https://aclanthology.org/2023.emnlp-main.398/)。
3. **先核身份与冲突。** 同款同规格和来源归属未经确认，不把上游页面或 SPU 的值直接赋给 SKU。标题、规格或图片冲突时保留各自证据，标冲突待核，不通过静默来源优先级任选。资料未读、读取失败、读后为空、证据不足、明确不适用和冲突是不同状态；未知不填 0、false、“其他”或默认值。
4. **校验并允许弃答。** 单位、计量对象、数值精度/范围依据、枚举及多选互斥要逐项检查；值域外留原文待维护，不能近似硬塞。无法定位证据、身份或来源冲突、无可靠转换、越界、歧义或质量门槛不达标时进入人工复核或待补证。模型自报置信度和两个模型相互同意不能直接当作可靠的错误概率。
5. **独立复核和回归。** 业务审核员对属性含义、来源及规范值做判断；规则检查发现结构错误，但不能单独证明专业正确。将真实冲突、单位混淆、同 SPU 不同规格、资料读取失败、图片误识别等形成带来源的回归样本，原始资料是证据而非指令。

选择性预测（selective prediction）可以在不确定时拒绝输出，换取已输出部分更低的错误风险；对应代价是覆盖率下降。论文在其任务和假设下讨论风险保证；这不是对本项目阈值或语言模型的现成保证。[Geifman、El-Yaniv，2017](https://proceedings.neurips.cc/paper/2017/hash/4a8423d5e91fda00bb7e46540e2b0cf1-Abstract.html)。

## 人工金标准与度量

先明确每类属性可接受的值、单位换算、枚举别名与边界，制定标注手册。抽样时冻结原始资料，标注员独立、尽量盲看模型结果，对可核值保留原文定位；不同意见和来源冲突进入仲裁，最终结果记录标注版本、仲裁意见及仍无法核实的状态。可在可行范围内对一部分样本双人独立标注，报告分歧和仲裁比例，避免把金标准当绝对真相。来源不完备时，金标准可以是“现有资料不足”，不能为了给模型评分强行猜一个值。

事先约定统计单元为**一件 SKU 的一个适用属性**，对每个请求 SKU 清楚记录失败；评估全部适用项目，包括系统弃答的项目。至少报告以下指标，均需标出分子、分母、统计范围、资料与合同版本：

| 指标 | 建议定义与用途 |
| --- | --- |
| 资料获取率 | 成功获取指定资料的 SKU 数 / 请求 SKU 数；同时单列未读、失败、空白和仅图片。它不是准确率。 |
| 自动采纳覆盖率 | 输出并通过预定自动采纳规则的 SKU × 属性数 / 全部纳入评价的适用 SKU × 属性数；排除不适用的规则和数量必须公开。 |
| 已采纳值准确率 / 风险 | 分别为金标准判定正确数、错误数 / 全部自动采纳值数。无证据、错误对象、错误规格或错误单位的采纳按证据合同算错，不能先排除；仍需仲裁而无法判定的单列。设总数 N、正确 C、错误 E、未判定 U，则准确率可报 C/N 至 (C+U)/N，风险可报 E/N 至 (E+U)/N，并报告 U；U=0 时才能将两者直接视为互补。 |
| 可核值召回率 | 系统正确自动采纳的可核值数 / 金标准在冻结证据范围内判为可核的值数；可测漏提和过度弃答，不排除系统弃答样本。 |
| 待审与冲突率 | 分别统计待补证、冲突、低把握、身份待核和人工复核量，按全部项目或 SKU 显示明确分母。 |

多选属性要先定评分：可报告整集合完全正确率，并辅助报告选项级精确率和召回率；同时保留部分漏选/多选错误，不能把部分相同直接记为整项正确。数值按已批准的对象、单位换算和精度比较，组合尺寸、方向和包装层级不可只按字符串近似相等。对证据错误、来源不匹配与值错误可另做分类，不能只看最终格式是否合规。

用开发/校准集设定规则或阈值，固定之后在独立留出的测试集报告风险—覆盖率及不确定性；需要选择阈值的，不能在同一测试集反复调整后仍把它当独立验收。按类目、属性类型、来源类型、冲突和有无图片分层，分别列出样本量与结果。若按业务配额抽样，整体推断需依据预先定义的目标总体、纳入概率和合适权重；少数层的结论受样本量限制。NIST 建议记录测试集、度量和不确定性，并以独立评估和类似实际部署的条件检验系统。[NIST AI RMF：Measure](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)。

## 零错误也有统计不确定性

作为说明，假设事先固定规则，从同一目标总体独立同分布抽到 **400 个已自动采纳、能由金标准判定**的测试单元，并且 400 个都无错。一侧 95% 精确二项误差率上界为：

```text
1 - 0.05^(1/400) ≈ 0.00746 = 0.746%
```

对应准确率一侧 95% 下界约为 99.254%；观察准确率虽为 400/400 = 100%，仍不能据此证明总体误差为零。这是具体假设下的统计界限，不是说真实错误率一定为 0.746%。零事件统计解释见 [Hanley、Lippman-Hand，1983](https://pubmed.ncbi.nlm.nih.gov/6827763/)。

这里的 400 是**独立评估单元**，不能自动把 400 个 SKU 的所有属性当成独立样本：同 SKU 多属性和同 SPU 多 SKU 的错误可能相关；本轮六类拟定配额也不是自动代表总体的随机样本。若按 SPU 聚类抽样、分层抽样、存在未判定项或只审了部分采纳值，应采用适配设计的估计和区间，并报告每层及聚类数量；简单套上述公式会过于乐观。即使人工复核全量 400 件，也只能对已复核范围给出结果和未决项，不能证明证据本身或未来商品绝无错误。

## 上线前的判断

先由业务按不同属性错误后果确定可接受风险与所需覆盖率，冻结规则后独立评估，再决定哪些结果可自动采纳、哪些必须人审以及何时停止。高风险属性可以采用更严格阈值或全量人工复核；资料不足时允许空缺。模型、提示词、来源、类目或属性合同变化时，重新检查受影响部分和风险—覆盖情况。离线产出与供应链写入是两个不同阶段；任何自动采纳的提取结果也不是自动写入授权。
