# 属性候选来源库

本库登记候选发现来源，保存原件与可检索索引。入库不等于属性采用，也不触发已治理类目的重建。最新接收日期为 2026-10-30；外部模板的官方版本、专业正确性和来源独立性未独立核验。文件内自述版本保留为原文，不等于验证其发布时间。

## 存储选择

当前使用 Excel/CSV 原件 + 结构化本地索引 + 来源登记，不引入数据库。人工查看原件，程序读取压缩 JSONL；检索时无需反复解析 Excel/CSV。原件是可追溯资料，索引可重建，二者职责分开。

当出现多人共同维护、频繁增量更新、类目映射/审批版本管理或线上查询服务需求时，再评估数据库。届时保留现有来源 ID、版本哈希、记录 ID 和原表定位，迁移检索与管理层，原件继续保存；不把数据库选型作为当前增加参考来源的前置条件。

## 后续任务如何使用

1. 确定目标商品对象，检索类目名、别名和同族概念；模板的类目树、编码、模板编号不等于三横类目 ID。同名也须核完整路径。模板编号可能重复，定位用来源版本 + sheet + 行号，或来源版本 + CSV 逻辑记录号。CSV 同时保留物理起止行，正确支持引号内换行。
2. 工业品优先检索震坤行模板与平台规格参考，其他模板、VOP、厂家专业资料和模型知识继续作为候选发现入口。优先级只影响检索顺序，不代表事实权威或自动采用。收集原词后再判断适用性、归并同义概念；保留各自来源，不能把多个模板的相同记录算成独立商品证据。两个震坤行数据集标注同一 `sourceFamilyId=zkh`，长宽 CSV 更是同一数据的两个视图，不产生第二份独立证据。
3. 品牌、供应商、销售单位、身份型号等仍按当前职责规范处理；外部模板的必填、MDM 映射、枚举和拆分方式只是原始资料，不覆盖本项目规则。优先短名、组合尺寸和数量单位合并，再给出完整定义。
4. `fields.*Raw` 和 `rawValues` 都是原文资料。示例不是目标 SKU 的已核实值，模板行数不是商品款数；模板参考不得贡献 `sourceSpuCount` 或声称本类直接商品观察。定义空缺不凭索引补写，研究和建模时再明确提出。
5. 纳入某轮时，将查询结果另存到该轮动态资料并记录哈希；`sourceReferences` 至少保留 sourceId、sourceFamilyId、recordId、原件路径/哈希、sheet 与行号或 CSV 逻辑记录号与物理行范围，以及适用性理由。完整原件随时可查，搜索未命中不表示该类目不能建模。
6. 只把来源路由和使用规则放固定上下文，按需分页取正文；不把全部模板记录整份塞进提示词。此次只接收资料，既有清洁用品方案、候选取舍与人审记录不回写。
7. 立讯模板的字典引用按原文保留。需要字典候选值时继续查原件 05，不能把“材质字典”当成一个枚举值，也不能默认整个字典适用于目标类目。类目绑定与汇总字典的类型、值域存在差异时并列记录，不以任一表静默覆盖另一表。具体观察见 [立讯模板研读记录](../../docs/luxshare-template-study-20261029.md)。
8. 震坤行 CSV 的 `fields.optionsRaw` 是平台选项原文，可供受控枚举候选研究，但不是已批准枚举或行业标准。索引不拆分分号、不统一单位、不判断合法性、不自动采用。`0L`、`无`、复合量和可能混维度值都原样保留，须逐项核商品对象、含义、量纲、单位、缺失占位语义与目标适用性后再决定取舍。平台存在选项不证明该选项合理，也不证明本项目应选择 ENUM 类型。

## 本地检索

在项目根目录执行，仅读已归档索引，不请求模型或外部服务：

```sh
bun src/scenarios/product_governance_v4/cli.ts query --kind references --category-text 垃圾袋 --limit 10
bun src/scenarios/product_governance_v4/cli.ts query --kind references --attribute-text 保质期 --source ai-competition-2 --limit 10
bun src/scenarios/product_governance_v4/cli.ts query --kind references --text 擦拭 --offset 0 --limit 20
bun src/scenarios/product_governance_v4/cli.ts query --kind references --source luxshare-template --category-text 垃圾袋 --limit 10
bun src/scenarios/product_governance_v4/cli.ts query --kind references --source zkh-l5-specs --category-text 电抗器 --attribute-text 额定电压 --limit 10
```

返回总命中数、下一页、原词、完整原始行和来源定位；`--record-id` 可精确回查。查询会检查目录、主原件、辅助原件、索引和核对报告哈希。当前为字面检索，不冒称语义召回。`query --kind references` 查四个本地来源；VOP 使用既有 `query --kind candidates|evidence --file ...`。网络和模型知识在后续研究中按需补充。

索引可重建，原工作簿和 CSV 不改写：

```sh
python3 src/scenarios/product_governance_v4/scripts/index-reference-templates.py
```

需要 openpyxl（本机 bundled Python 已提供）。压缩索引是无损 JSONL，保留所有属性行及原始单元格值；CSV 用标准解析器读取，保留字符串、前导零及引号内换行，拒绝列数不一致。空行可略过，缺类目或属性则报错，不猜填。新版本原件另行归档并更新接收回执与配置，catalog 变化后重建全部来源与 manifest，不静默替换已引用版本。
